🎓 Academic Explanation & Foundational Math

1. The Stochastic Markov Decision Process (MDP)

This smart grid optimization task is modeled as a continuous-state, continuous-action stochastic Markov Decision Process (MDP) defined by the five-tuple \((\mathcal{S}, \mathcal{A}, P, R, \gamma)\). The continuous state space \(\mathcal{S}\) tracks four dimensions: the battery normalized State of Charge (SoC), electricity pricing, solar irradiance generation, and the time of day. Crucially, the transition dynamics function \(P(s' | s, a)\) incorporates environmental volatility through first-order Autoregressive (AR(1)) stochastic processes mapping both the pricing schedule and local photovoltaic generation:

\[p_{t+1} = \mu_p + \phi_p(p_t - \mu_p) + \epsilon^p_t, \quad \epsilon^p_t \sim \mathcal{N}(0, \sigma_p^2)\] \[g_{t+1} = \mu_g + \phi_g(g_t - \mu_g) + \epsilon^g_t, \quad \epsilon^g_t \sim \mathcal{N}(0, \sigma_g^2)\]

Here, the stochastic price and solar signals are updated using stationary coefficients \(\phi_p = 0.8\) and \(\phi_g = 0.7\), combined with independent normal error perturbations \(\epsilon^p\) and \(\epsilon^g\) that prevent unrealistic high-frequency variance while retaining daily periodicity constraints.

2. Soft Actor-Critic (SAC) Maximum Entropy Objective

To operate effectively in highly volatile and unpredictable pricing landscapes, the decision agent is trained using the off-policy Soft Actor-Critic (SAC) framework. SAC expands the traditional expected return formulation of reinforcement learning by maximizing the policy's structural entropy alongside standard long-term reward. The maximum entropy objective function \(J(\pi)\) is mathematically stated as:

\[J(\pi) = \sum_{t=0}^{\infty} \mathbb{E}_{(s_t, a_t) \sim \rho_\pi} \left[ R(s_t, a_t) + \alpha \mathcal{H}(\pi(\cdot | s_t)) \right]\]

where \(\mathcal{H}(\pi(\cdot | s_t)) = -\int_{A} \pi(a|s_t) \log \pi(a|s_t) da\) is the operational policy entropy, and \(\alpha\) is the dynamic temperature parameter balancing exploration drive against standard optimization. By incentivizing the neural network to explore highly diverse path sequences, entropy regularization prevents premature collapse of the continuous control actor into sub-optimal local basins (such as simple, short-sighted greedy trading schemes).

3. Physics Boundary Constraints & Shaping Calculus

To enforce grid stability, system safety, and longevity, the reward framework employs multi-objective reward shaping. The aggregate reward \(R(s,a)\) is defined as:

\[R_t = - \left( \frac{P_t \cdot \rho_t \cdot \Delta t}{1000} \right) w_{\text{arb}} + \max(0, -P_t \cdot S_t \cdot w_{\text{green}}) - |P_t| \cdot \Delta t \cdot C_{\text{deg}} \left( 1 + \lambda (T_{\text{cell}} - T_{\text{nom}})^2 \right) w_{\text{wear}} - w_{\text{soc}} (SoC_t - 0.5)^2\]

Where energy arbitrage \(R_{\text{arbitrage}}\) optimizes direct grid cost-efficiency, utilizing local charging efficiency \(\eta\) that degrades quadratically as SoC approaches full capacity. Degradation penalty \(R_{\text{wear}}\) implements dynamic Depth-of-Discharge (DoD) wear tracking proportional to absolute power flow and battery cell thermal heating, incentivizing battery longevity.

📖 Smart Grid Load Agent System Guide

1. System Architecture

The project is structured with a decoupled reinforcement learning core and an interactive frontend simulation engine. It enables rapid prototyping of physical environment configurations and immediate validation of trained policy performance.

📁 environments.py

Implements the production-grade stochastic microgrid Gymnasium environment. Manages AR(1) price/solar transitions, thermal dynamics, and reward shaping.

📁 train.py

Orchestrates model training using Stable-Baselines3 Soft Actor-Critic (SAC). Fits VecNormalize checkpoints and exports model weights.

📁 app.py / index.html

Interactive interfaces. app.py runs via python Streamlit server, and index.html executes as a client-side ES6 browser simulation.

2. Quick Start & Replication Guide

Follow these steps to replicate the training loop and verify the policy code locally:

# 1. Clone the project repository
git clone https://github.com/tejaswin-amara/Smart-Grid-Load-Decision-Agent.git
cd Smart-Grid-Load-Decision-Agent

# 2. Install dependencies (Requires Python 3.9+)
pip install -r requirements.txt

# 3. Train the SAC RL Agent
python train.py

# 4. Run the automated testing suite
python -m pytest tests/ -v

3. Testing Framework

The codebase is covered by 24 unit and regression tests mapping physics boundaries, episode terminations, seed reproducibility, and policy boundaries:

  • tests/test_env.py: Validates Gymnasium constraints, seed determinism, and reward shaping components.
  • tests/test_policy.py: Evaluates policy responses under peak grid prices and abundant solar surplus.
  • tests/test_simulation.py: Tests Markov Chain weather state shifts and physical step integrations.
